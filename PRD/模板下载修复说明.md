# 模板下载问题修复说明

## 问题原因

模板下载失败主要由以下问题导致：

### 1. **文件名编码问题**（潜在）
- 原代码使用中文文件名 `"业务数据输入模板.xlsx"`
- 在某些环境/浏览器中可能出现编码问题

### 2. **临时文件管理不当**
- 使用 `tempfile.NamedTemporaryFile` 可能遇到权限问题
- 缺少文件清理机制，可能堆积临时文件

### 3. **前端错误处理不完善**
- 无法区分成功响应和错误响应（都是 blob 类型）
- 错误信息不明确

## 修复内容

### 后端修复（backend/main.py）

#### 1. 改进文件存储位置
```python
# 在 backend/data/temp 目录下创建文件，避免权限问题
temp_dir = Path(__file__).parent / "data" / "temp"
temp_dir.mkdir(parents=True, exist_ok=True)
temp_file_path = temp_dir / f"template_{os.urandom(4).hex()}.xlsx"
```

#### 2. 使用英文文件名
```python
filename="business_data_template.xlsx"  # 避免中文编码问题
```

#### 3. 添加自动清理机制
```python
# 清理旧文件（保留1小时内的）
_cleanup_old_temp_files(temp_dir, max_age_hours=1)

# 使用 BackgroundTasks 在发送后删除文件
background_tasks = BackgroundTasks()
background_tasks.add_task(_remove_file, path=str(temp_file_path))
```

#### 4. 增强错误处理
```python
except Exception as e:
    # 出错时立即清理
    if temp_file_path and temp_file_path.exists():
        temp_file_path.unlink()
    logger.exception(f"生成模板失败: {e}")
    raise HTTPException(status_code=500, detail=f"生成模板失败: {str(e)}")
```

### 前端修复（frontend/src/components/CreateStatementModal.tsx）

#### 1. 增强错误处理
```typescript
// 检查响应是否为错误（如果出错，后端可能返回 JSON 而非 blob）
if (response.data?.type === 'application/json') {
  const reader = new FileReader();
  reader.onload = () => {
    try {
      const error = JSON.parse(reader.result as string);
      message.error(error.detail || '模板生成失败');
    } catch {
      message.error('模板生成失败');
    }
  };
  reader.readAsText(response.data);
  return;
}
```

#### 2. 添加超时设置
```typescript
const response = await axios.get(apiUrl('/templates/input/download'), {
  responseType: 'blob',
  timeout: 10000, // 10秒超时
});
```

#### 3. 详细的错误分类
```typescript
if (error.response) {
  // 服务器返回错误
  message.error(`下载失败: ${error.response.data?.detail || '服务器错误'}`);
} else if (error.request) {
  // 请求发送但没有收到响应
  message.error('下载失败: 无法连接到服务器，请检查网络');
} else {
  // 请求配置出错
  message.error(`下载失败: ${error.message || '未知错误'}`);
}
```

#### 4. 添加调试日志
```typescript
console.log('模板下载响应:', {
  status: response.status,
  contentType: response.headers['content-type'],
  size: response.data?.size || response.data?.length,
});
```

## 注意事项

### 1. 文件保存位置
- 模板临时文件保存在 `backend/data/temp/`
- 保留1小时内的文件，超期自动清理
- 下载完成后立即删除（通过 BackgroundTasks）

### 2. 浏览器兼容性
- 使用标准的 Blob 和 URL.createObjectURL API
- 支持所有现代浏览器
- 下载文件名在前端设置（中文）

### 3. 权限要求
- 确保 `backend/data/` 目录可写
- 确保 `backend/data/temp/` 目录可写（自动创建）

### 4. 网络问题
- 超时设置为 10 秒
- 连接失败会提示"无法连接到服务器"
- 服务端错误会显示具体错误信息

## 故障排查

如果仍然下载失败，请检查：

1. **查看浏览器控制台**
   ```
   F12 → Console → 查看红色错误信息
   ```

2. **查看后端日志**
   ```
   tail -f backend/logs/app.log
   ```

3. **检查目录权限**
   ```bash
   ls -la backend/data/
   mkdir -p backend/data/temp
   chmod 755 backend/data/temp
   ```

4. **测试 API 直接访问**
   ```bash
   curl http://localhost:8000/api/templates/input/download \
     -o test_template.xlsx \
     -H "Accept: application/vnd.openxmlformats-officedocument.spreadsheetml.sheet"
   ```
